# VEX Customer Success

Plataforma de CS (health score, Curva ABC, jornada do cliente, playbooks, suporte). Vite + React + TypeScript.

## Rodar
    npm install
    npm run dev

## Estrutura
- `src/legacy/vex.css` — tema VEX extraído do protótipo
- `src/legacy/data.js` — regras (faixas, pilares, curva ABC, playbooks) e dados de exemplo
- `src/pages/` — telas portadas: Visão geral e Carteira
- `legacy/VEX_Customer_Success.html` — protótipo original (referência para portar as demais telas)

## Pendente de portar
Cliente 360, Tarefas, Mudanças de faixa, Playbooks, Suporte, Logs e Regras.
